# ☕ Coffee Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing coffee sales data using Microsoft Power BI. The dashboard provides interactive visualizations and key performance indicators (KPIs) to understand sales performance, product demand, customer purchasing patterns, and business trends.

The main objective of this project is to transform raw sales data into meaningful insights that can help businesses make data-driven decisions and improve sales performance.

## 🎯 Project Objectives

- Analyze overall coffee sales performance.
- Track total sales, quantity sold, and order trends.
- Identify the best-selling coffee products.
- Analyze sales performance over time.
- Compare product categories and customer preferences.
- Build an interactive dashboard for business decision-making.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel / CSV** – Data source

## 📊 Key Performance Indicators (KPIs)

- Total Sales Revenue
- Total Orders
- Total Quantity Sold
- Average Sales / Order Value, if included in the dashboard
- Monthly Sales Performance

*Note: The KPIs listed above should match the actual measures in your dashboard.*

## 📈 Dashboard Features

- Interactive charts and graphs
- Sales trend analysis
- Product-wise sales comparison
- Category-wise performance analysis
- Monthly and yearly sales analysis, where applicable
- Interactive filters and slicers
- Clear KPI cards for quick performance monitoring

## 🔍 Key Business Questions

1. What is the total revenue generated from coffee sales?
2. Which coffee products generate the highest sales?
3. How do sales change over time?
4. Which product categories perform best?
5. What are the major sales trends and patterns?
6. How can the business use sales data to improve performance?
